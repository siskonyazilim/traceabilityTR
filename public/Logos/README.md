# Logo Dosyaları

Bu klasöre aşağıdaki logoları ekleyin:

## Strategik Ortak Logoları

```
sick-logo.png              - SICK sensör teknolojileri
universal-robots-logo.png  - Universal Robots (cobot)
markem-imaje-logo.png      - Markem-Imaje kodlama
interroll-logo.png         - Interroll malzeme taşıma
sewio-logo.png             - Sewio RTLS sistemleri
```

## Referans Proje Logoları (Müşteriler)

```
maxion-inci.png            - Maxion İnci Çelik
abalıoglu.png              - Abalıoğlu Yağ
nuhun.png                  - Nuh'un Ankara
delphi.png                 - Delphi Technologies
pmi.png                    - PMI
```

## Gerekli Formlar

- Format: PNG (transparent background) veya SVG (vektör)
- Boyut: 200x200px (minimum 150x150px)
- Renk: Renkli orijinal logoları tercih edin
- Dosya adları: Küçük harfler, boşluk yok (kebab-case)

## Kullanım

Logoları ekledikten sonra:

```
/public/logos/sick-logo.png
/public/logos/universal-robots-logo.png
... vb
```

## Not

Tüm logoları tamamen yeniden başlangıçtan tasarlamak zorunda değilsiniz. 
Orijinal şirket sitelerinden PNG/SVG formatında indirebilirsiniz.

Alternatif: Logo placeholder'ları kullanabilirsiniz (şirket adı yazısı).
